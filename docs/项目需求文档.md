### 3.4 NNC6521 双芯片引脚映射

本项目使用两颗 NNC6521 微电流刺激芯片，通过软件 SPI（GPIO Bit-Bang）驱动。

| 功能 | Chip 1（NNC6521_1） | Chip 2（NNC6521_2） |
|------|---------------------|---------------------|
| MOSI | PC9 | PB13 |
| CSN | PC8 | PB12 |
| SCLK | PC7 | PB11 |
| MISO | PA8 | PB14 |
| CHIP_EN | PA12 | PC6 |
| INTB（中断） | PA11 | PB15 |

**SPI 时序**: CPOL=0, CPHA=0, MSB First  
**写协议**: 4 字节 `[addr, cmd(0x80/0xC0), 0x11, data]`  
**读协议**: 3 字节 `[addr, cmd(0x00/0x40), dummy]` → 返回数据  
**cmd 含义**: `0x80` = 普通寄存器写, `0xC0` = 波形寄存器写, `0x00` = 普通寄存器读, `0x40` = 波形寄存器读

## 五、通信协议

### 5.1 帧格式

```
+--------+--------+------+--------+--------+------+-------+------+-------+-------+
| HEAD1  | HEAD2  | LEN  | ADDR_H | ADDR_L | TYPE | STATE | FUNC | PARAMS| CRC16 |
| 0x55   | 0xAA   | var  | 0x60   | 0x66   | var  | var   | var  | var   | 2B    |
+--------+--------+------+--------+--------+------+-------+------+-------+-------+
```

| 字段 | 长度 | 说明 |
|------|------|------|
| HEAD1 | 1B | 固定 0x55 |
| HEAD2 | 1B | 固定 0xAA |
| LEN | 1B | 从 LEN 字段本身到 PARAMS 末尾的字节数（不含 HEAD1/HEAD2，不含 CRC） |
| ADDR_H | 1B | 设备地址高字节（0x60） |
| ADDR_L | 1B | 设备地址低字节（0x66） |
| TYPE | 1B | 帧类型：0x44=动作命令，0x45=参数查询 |
| STATE | 1B | 帧状态：0x02=主机请求(ASK)，0x01=设备应答(ACK) |
| FUNC | 1B | 功能码（0x01~0x09） |
| PARAMS | NB | 功能参数（长度由 LEN 决定） |
| CRC16 | 2B | CRC16-MODBUS，计算范围为 LEN ~ PARAMS 末尾 |

### 5.2 CRC16-MODBUS 算法

- 初始值: `0xFFFF`
- 多项式: `0xA001`（反转）
- 计算范围: LEN 字段到 PARAMS 最后一个字节

### 5.3 解码状态机

```
IDLE → HEAD2 → LENGTH → ADDR_H → ADDR_L → PAYLOAD → CRC_H → CRC_L
  ↑                                                             │
  └─────────────────── 校验失败 / 正常完成 ──────────────────────┘
```

### 5.4 串口缓冲区配置

| 参数 | 值 |
|------|-----|
| 接收环形缓冲区 | 512 字节 |
| 发送缓冲区 | 64 字节 |
| 最大帧长度 | 64 字节 |
| 命令解码缓冲区 | 32 字节 |
| UART 接收缓冲区 | 1024 字节（rt_device buf） |

## 六、功能需求（分模块）

### 6.1 手柄切换模块（功能码 0x01）

**功能描述**: 切换当前活动手柄。

| 手柄 ID | 手柄名称 | 功能 |
|---------|---------|------|
| 0x0A | 手柄 A | 微电流 + 加热 |
| 0x0B | 手柄 B | 微电流 + 加热 |
| 0x0C | 手柄 C | 微电流 + 泵 |

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| handle_id | 1B | 目标手柄 ID（0x0A/0x0B/0x0C） |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| handle_id | 1B | 已切换到的手柄 ID |

**行为**:
1. 切换前自动停止当前波形输出
2. 关闭所有加热输出（大手柄/小手柄）
3. 关闭气泵
4. 清零所有手柄的参数（电流百分比、目标温度、泵转速），三手柄互斥
5. 重置所有手柄的 PID 温控目标为 0
6. 更新全局 `current_handle` 字段，`is_running` 置 0
7. 校验 handle_id 合法性，非法则返回错误码 0x01

### 6.2 电流控制模块（功能码 0x02）

**功能描述**: 设置指定手柄的微电流输出百分比。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| percent | 1B | 电流百分比（0~100），映射到当前波形的电流范围 |
| handle_id | 1B | 目标手柄 ID |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| percent | 1B | 设置的百分比 |
| handle_id | 1B | 目标手柄 ID |

**行为**:
1. 保存到目标手柄的 `current_percent` 字段
2. 若目标手柄为当前活动手柄，立即更新 NNC6521 输出
3. 百分比映射公式: `actual_current = min + (max - min) × percent / 100`

### 6.3 温度控制模块（功能码 0x03）

**功能描述**: 设置手柄加热目标温度。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| temperature | 1B | 目标温度（0~41℃，0=关闭加热） |
| handle_id | 1B | 目标手柄 ID（仅支持 0x0A 和 0x0B） |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| temperature | 1B | 设置的温度值 |
| handle_id | 1B | 目标手柄 ID |

**行为**:
1. 温度范围限制: 0~41℃
2. 仅手柄 A 和 B 支持加热（手柄 C 不支持）
3. 温度=0 时关闭加热，>0 时开启加热控制
4. 内部 PID 温控模块自动调节加热功率（详见 NTC 温度 PID 控制算法设计文档）

### 6.4 泵控制模块（功能码 0x04）

**功能描述**: 控制手柄 C 的泵转速。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| speed | 1B | 泵转速百分比（0~100，0=停止） |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| speed | 1B | 设置的转速百分比 |

**行为**:
1. 泵仅适用于手柄 C（索引 2）
2. 转速范围: 0~100%
3. 通过 PB10 GPIO 控制（高电平使能，低电平关闭），简单开/关控制，无 PWM 调速

### 6.5 开始/暂停模块（功能码 0x05）

**功能描述**: 控制治疗过程的开始和暂停。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| action | 1B | 0x00=暂停，0x01=开始 |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|

**行为**:
- **开始 (0x01)**:
  1. 设置 `is_running = 1`
  2. 调用 `protocol_update_current_output()` 按当前手柄的百分比映射电流
  3. **TODO**: 启用 NNC6521 波形发生器
- **暂停 (0x00)**:
  1. 设置 `is_running = 0`
  2. **TODO**: 禁用 NNC6521 波形发生器

### 6.6 OTA 升级模块（功能码 0x06）

**功能描述**: 远程固件升级（**预留功能，当前未实现**）。

### 6.9 波形选择模块（功能码 0x09）

### 7.2 电流映射规则

电流百分比 (0~100%) 线性映射到各波形的有效电流范围：

```
actual_current = min_current + (max_current - min_current) × percent / 100
```

| 波形 ID | min_current (mA) | max_current (mA) |
|---------|------------------|------------------|
| 1 | 30 | 80 |
| 2 | 30 | 80 |
| 3 | 20 | 60 |
| 4 | 30 | 80 |
| 5 | 30 | 80 |
| 6 | 20 | 60 |
| 7 | 15 | 50 |
| 8 | 15 | 40 |
| 9 | 10 | 30 |

### 7.3 波形生成方式

NNC6521 支持三种波形生成方式：

1. **预加载波形 (Preloaded)**: 芯片内置的正弦/脉冲/三角波，通过寄存器选择
2. **自定义波形 (Customized SPI)**: 通过 SPI 写入归一化浮点数组，由芯片 DAC 输出
3. **幅度调制 (Amplitude Modulation)**: 包络线 + 载波的调制输出

### 7.4 波形数据采样点

| 数据类型 | 采样点数 | 用途 |
|---------|---------|------|
| `normalized_sine_waveform_16` | 16 | 低精度正弦 |
| `normalized_sine_waveform_64` | 64 | 标准正弦（含半波拆分） |
| `normalized_sine_waveform_128` | 128 | 高精度正弦（含半波拆分） |
| `normalized_triangle_waveform_64` | 64 | 标准三角波（含半波拆分） |
| `normalized_triangle_waveform_128` | 128 | 高精度三角波（含半波拆分） |
| `normalized_pulse_waveform_128` | 128 | 脉冲波 |
| `normalized_user_waveform_128` | 128 | 自定义用户波形（指数衰减包络） |

### 7.5 波形点数选择规则

| 波形 ID | 采样点数 | 说明 |
|---------|---------|------|
| 4, 5, 6 | 128 | 高频/复杂波形使用更多采样点 |
| 其他 | 64 | 标准波形 |

### 8.1 手柄配置

| 手柄 | ID | 功能 | ADC 通道 | 加热控制引脚 | 泵控制 |

### 9.2 电源状态机

```
┌──────────┐  Flag.power_boot_request=1  ┌──────────┐
│  OFF     │ ─────────────────────────→  │ BOOTING  │
│ (待机)   │                             │ (开机中)  │
└──────────┘                             └────┬─────┘
     ↑                                        │ power_boot_sequence()
     │ power_do_shutdown()                    ↓
     │                                  ┌──────────┐
┌──────────┐  Flag.power_shutdown_      │   ON     │
│ SHUTTING │ ←  request / force ────── │ (运行中)  │
│  DOWN    │                            └──────────┘
└──────────┘
```

### 9.3 开机流程

触发条件：`KEY_Scan()` 检测到 `KEY_Evt_Press` 事件 → 设置 `Flag.power_boot_request = 1`

执行序列（`power_boot_sequence()`）：
1. `LED_On(LED_Name_Green)` — PA6 指示灯常亮
2. `BEEP_SetCycleDuty(1000, 1000)` + `BEEP_Blink(1, 0, 0)` — PA7 蜂鸣器响 1s（非阻塞）
3. `bsp_power_enable(1)` — PA4 12V 系统电源使能
4. **不使能 54V 升压**（仅在电刺激输出时开启）
5. 状态切换为 `POWER_STATE_ON`

### 9.4 优雅关机流程

触发条件：`KEY_Scan()` 检测到 `KEY_Evt_Long2S` 事件 → 设置 `Flag.power_shutdown_request = 1`

执行序列（`power_shutdown_graceful()`）：
1. 发送关机请求帧（func=0x0A, para=0x00）给上位机
2. 等待上位机回复确认（Flag.power_shutdown_confirmed=1），超时 5s 强制关机
3. `protocol_stop_waveform()` — 停止所有波形输出
4. `bsp_heater_large_set(0)` + `bsp_heater_small_set(0)` — 关闭加热
5. `bsp_pump_set(0)` — 关闭气泵
6. `bsp_boost_1_enable(0)` + `bsp_boost_2_enable(0)` — 关闭 54V 升压
7. `bsp_power_enable(0)` — 关闭 12V 电源
8. `BEEP_Blink(1, 0, 0)` + 延时 1s — 蜂鸣器响一声
9. `LED_Off(LED_Name_Green)` — 关闭指示灯
10. 状态切换为 `POWER_STATE_OFF`

### 9.5 强制关机流程

触发条件：`KEY_Scan()` 检测到 `KEY_Evt_Long4S` 事件 → 设置 `Flag.power_force_shutdown = 1`

执行序列：跳过上位机确认，直接执行步骤 3~10（同优雅关机）

### 9.6 关机请求协议

| 方向 | 帧内容 | 说明 |
|------|--------|------|
| 设备→上位机 | `55 AA 06 60 66 44 01 0A 00 [crcH] [crcL]` | 关机请求（func=0x0A, para=0x00） |
| 上位机→设备 | `55 AA 06 60 66 44 02 0A 01 [crcH] [crcL]` | 关机确认（func=0x0A, para=0x01） |

## 十一、NNC6521 驱动层

### 11.1 芯片初始化流程

```
1. nnc6521_gpio_init()         → 初始化所有 GPIO 引脚
2. nnc6521_init(chip_id)       → 上电序列:
   a. CHIP_EN = LOW（复位）
   b. 延时 ~10ms
   c. CHIP_EN = HIGH（使能）
   d. 延时 ~10ms
   e. 写 PMU 寄存器: 复位波形发生器
   f. 配置时钟: PCLK 分频 = 1（2MHz）
   g. 全局驱动使能
```

### 11.2 波形发生器配置流程

```
1. 禁用目标通道 AWG
2. 使能模拟通道 (ANA_ENABLE_REG)
3. 写入配置寄存器组:
   - 采样点数 (POINT_CONFIG)
   - 配置寄存器 (CONFIG_REG0): rest/negative/silent/sourceB/multi_electrode/continue
   - 静默时间 (SILENT_CLK): 24-bit
   - 正半波间隔 (HALF_WAVE_CLK_PNT): 16-bit
   - 负半波间隔 (NEG_HALF_WAVE_CLK_PNT): 16-bit
   - 驱动电流寄存器 2 (DRIVE_REG_CTRL2)
   - 死区时间 (REST_CLK): 16-bit
   - 中断配置 (INT_NUM_WAVE, INT_REG01~03)
4. 若为 SPI 波形:
   a. 通过 OTP 校准数据计算电流
   b. 生成缩放波形数组 (16-bit → 8-bit)
   c. 逐点写入波形数据到 Waveform RAM
5. 配置交替模式寄存器
6. 使能 AWG
```

### 11.3 电流校准系统

- 校准数据存储在 NNC6521 OTP 内存中
- 25 个校准点（范围 3~25）
- CH1 校准基地址: `0x00`
- CH2 校准基地址: `0x32`
- 校准流程: 读取 OTP Dref → 计算 Ival = (Ireq × 1000) / Dref → 限制最大 4096

### 11.4 安全检测

#### 11.4.1 导联脱落检测 (LOD - Lead-Off Detection)

- 检测模式: 高电平检测
- 检测通道: CH1 + CH2 同时（LO_ALL）
- 寄存器组: `0x30~0x3B`（LEAD_OFF_xxx）
- 中断使能位: `LEAD_OFF_INT.lead_off_int_en`
- 配置参数: 阈值（16-bit）、延迟、目标值

#### 11.4.2 短路检测 (SCD - Short-Circuit Detection)

- 双通道独立检测
- 通过 DAC 阈值比较器实现
- 寄存器组: `ANA_INT_SIMx_xxx`, `ANA_INT_CHx_INT_NUMBER`
- 中断清零: 写 `ANA_INTR_SIM_CL = 0x03`
