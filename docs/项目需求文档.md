### 3.4 NNC6521 双芯片引脚映射

本项目使用两颗 NNC6521 微电流刺激芯片，通过软件 SPI（GPIO Bit-Bang）驱动。

| 功能 | Chip 1（NNC6521_1） | Chip 2（NNC6521_2） |
|------|---------------------|---------------------|
| MOSI | PC9 | PB13 |
| CSN | PC8 | PB12 |
| SCLK | PC7 | PB11 |
| MISO | PA8 | PB14 |
| CHIP_EN | PA12 | PC6 |
| INTB（中断） | PA11 | PB15 |

**SPI 时序**: CPOL=0, CPHA=0, MSB First  
**写协议**: 4 字节 `[addr, cmd(0x80/0xC0), data, 0x00]`  
**读协议**: 3 字节 `[addr, cmd(0x00/0x40), dummy]` → 返回数据  
**cmd 含义**: `0x80` = 普通寄存器写, `0xC0` = 波形寄存器写, `0x00` = 普通寄存器读, `0x40` = 波形寄存器读  
**位操作时序**: MOSI 建立后 4x NOP (~55ns)，SCLK 高电平 8x NOP，SCLK 低电平 4x NOP  
**CHIP_EN 复位**: 低电平 ≥1ms → 高电平 ≥5ms

## 五、通信协议

### 5.1 帧格式

```
+--------+--------+------+--------+--------+------+-------+------+-------+-------+
| HEAD1  | HEAD2  | LEN  | ADDR_H | ADDR_L | TYPE | STATE | FUNC | PARAMS| CRC16 |
| 0x55   | 0xAA   | var  | 0x60   | 0x66   | var  | var   | var  | var   | 2B    |
+--------+--------+------+--------+--------+------+-------+------+-------+-------+
```

| 字段 | 长度 | 说明 |
|------|------|------|
| HEAD1 | 1B | 固定 0x55 |
| HEAD2 | 1B | 固定 0xAA |
| LEN | 1B | 从 LEN 字段本身到 PARAMS 末尾的字节数（不含 HEAD1/HEAD2，不含 CRC） |
| ADDR_H | 1B | 设备地址高字节（0x60） |
| ADDR_L | 1B | 设备地址低字节（0x66） |
| TYPE | 1B | 帧类型：0x44=动作命令，0x45=参数查询 |
| STATE | 1B | 帧状态：0x02=主机请求(ASK)，0x01=设备应答(ACK) |
| FUNC | 1B | 功能码（0x01~0x0A） |
| PARAMS | NB | 功能参数（长度由 LEN 决定） |
| CRC16 | 2B | CRC16-MODBUS，计算范围为 LEN ~ PARAMS 末尾 |

### 5.2 CRC16-MODBUS 算法

- 初始值: `0xFFFF`
- 多项式: `0xA001`（反转）
- 计算范围: LEN 字段到 PARAMS 最后一个字节

### 5.3 解码状态机

```
IDLE → HEAD2 → LENGTH → ADDR_H → ADDR_L → PAYLOAD → CRC_H → CRC_L
  ↑                                                             │
  └─────────────────── 校验失败 / 正常完成 ──────────────────────┘
```

### 5.4 串口缓冲区配置

| 参数 | 值 |
|------|-----|
| 接收环形缓冲区 | 512 字节 |
| 发送缓冲区 | 64 字节 |
| 最大帧长度 | 64 字节 |
| 命令解码缓冲区 | 32 字节 |
| UART 接收缓冲区 | 1024 字节（rt_device buf） |

## 六、功能需求（分模块）

### 6.1 手柄切换模块（功能码 0x01）

**功能描述**: 切换当前活动手柄。

| 手柄 ID | 手柄名称 | 功能 |
|---------|---------|------|
| 0x0A | 手柄 A | 微电流 + 加热 |
| 0x0B | 手柄 B | 微电流 + 加热 |
| 0x0C | 手柄 C | 微电流 + 泵 |

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| handle_id | 1B | 目标手柄 ID（0x0A/0x0B/0x0C） |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| handle_id | 1B | 已切换到的手柄 ID |

**行为**:
1. 切换前自动停止当前波形输出
2. 关闭所有加热输出（大手柄/小手柄）
3. 关闭气泵
4. 清零所有手柄的参数（电流值、目标温度、泵转速），三手柄互斥
5. 重置所有手柄的 PID 温控目标为 0
6. 更新全局 `current_handle` 字段，`is_running` 置 0
7. 校验 handle_id 合法性，非法则返回错误码 0x01
8. 关闭旧手柄对应的 54V boost
9. 关闭所有加热器和气泵硬件

### 6.2 电流控制模块（功能码 0x02）

**功能描述**: 设置指定手柄的微电流输出值(mA)。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| current_ma | 1B | 电流值（mA，0~100），直接传入 mA 值，固件自动 clamp 到波形范围 |
| handle_id | 1B | 目标手柄 ID |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| current_ma | 1B | 设置的 mA 值 |
| handle_id | 1B | 目标手柄 ID |

**行为**:
1. 保存到目标手柄的 `current_ma` 字段
2. 若目标手柄为当前活动手柄，立即更新 NNC6521 输出
3. 固件 clamp 逻辑：若 mA < 波形最小电流，输出波形最小电流；若 mA > 波形最大电流，输出波形最大电流

### 6.3 温度控制模块（功能码 0x03）

**功能描述**: 设置手柄加热目标温度，通过 PID 算法自动调节加热功率。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| temperature | 1B | 目标温度（0~41℃，0=关闭加热） |
| handle_id | 1B | 目标手柄 ID（仅支持 0x0A 和 0x0B） |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| temperature | 1B | 设置的温度值 |
| handle_id | 1B | 目标手柄 ID |

**手柄-温控映射**:
| 手柄 | PID 实例 | 加热器 | 说明 |
|------|----------|--------|------|
| A (0x0A) | TEMP_PID_SMALL | 小手柄加热器 (PC10) | 小手柄温控 |
| B (0x0B) | TEMP_PID_LARGE | 大手柄加热器 (PC11) | 大手柄温控 |
| C (0x0C) | 无 | 无 | 不支持加热，返回错误 |

**行为**:
1. 温度范围限制: 0~41℃
2. 仅手柄 A 和 B 支持加热（手柄 C 返回错误）
3. 温度=0 时关闭加热，>0 时启用 PID 控温
4. **温控互斥**: 设置一个手柄的温度时，自动关闭另一个手柄的 PID 控制器
5. 调用 `temp_pid_set_target()` 设置目标温度，PID 控制器自动调节加热占空比
6. 温控完整流程:
   ```
   上位机发温度指令 → handle_temp_ctrl() → temp_pid_set_target(ch, 37°C)
                                                 ↓
   10ms 定时器 → ntc_sensor_update()（ADC 读取 + 滤波 + 查表 → 温度值）
              → temp_pid_tick()（每 100ms：PID 计算 → 软件 PWM → GPIO 控制）
   ```
7. 安全保护:
   - 过热 45°C 强制关断
   - 传感器故障检测（连续 10 次异常）
   - 积分抗饱和（I_MAX=80, I_MIN=-10）
   - 死区 0.3°C（避免继电器抖动）
   - 超温保护（超过目标 1°C 强制输出 0，积分衰减 5%）

### 6.4 泵控制模块（功能码 0x04）

**功能描述**: 通过 DAC7311 调压控制手柄 C 的泵转速。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| speed | 1B | 泵转速百分比（0~100，0=停止） |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| speed | 1B | 设置的转速百分比 |

**硬件接口**:
| 组件 | 说明 |
|------|------|
| DAC7311 | 12-bit SPI DAC，输出 0~5V |
| PB7 | DAC7311_SYNC（片选，低电平有效） |
| PB8 | DAC7311_SCLK（时钟） |
| PB9 | DAC7311_DIN（数据） |
| VOUT | 泵驱动电压 = speed% × 5V |

**行为**:
1. 泵仅适用于手柄 C（索引 2）
2. 转速范围: 0~100%
3. 通过 DAC7311 输出模拟电压控制泵转速（0~5V）
4. 收到泵速命令后联动硬件：`dac7311_set_percent(speed)`
5. 速度=0 时输出 0V（泵停止），速度=100 时输出 5V（满速）
6. 切手柄或关机时自动关闭泵：`dac7311_set_percent(0)`

**DAC7311 驱动规格**:
- 分辨率：12-bit（0~4095）
- 输出电压：VOUT = VREF × D / 4096（VREF = VDD = 5V）
- SPI 协议：Mode 0（CPOL=0, CPHA=0），16-bit 帧，MSB 先传
- 帧格式：[X X PD1 PD0 D11 D10 ... D0]，PD=00 表示正常工作

**泵控完整流程**:
```
上位机发泵速指令 [0x04, 50]（50%）
        ↓
handle_pump_ctrl()
   - 校验 speed ≤ 100
   - 保存 pump_speed = 50
   - dac7311_set_percent(50)
     → 计算：VOUT = 5.0 × 50 / 100 = 2.5V
     → 计算：D = 2.5 / 5.0 × 4095 = 2047
     → SPI 写入帧：[00 00 07 FF]（PD=00, D=2047=0x7FF）
   - 返回 ACK [0x32]
        ↓
切手柄 / 关机
   → dac7311_set_percent(0) → 输出 0V → 泵停止
```

### 6.5 开始/暂停模块（功能码 0x05）

**功能描述**: 控制治疗过程的开始和暂停。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| action | 1B | 0x00=暂停，0x01=开始 |

**应答参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| action | 1B | 执行的动作 |

**行为**:
- **开始 (0x01)**:
  1. 使能对应手柄的 54V boost（Handle A/B → PB0, Handle C → PB1）
  2. 延时 10ms 等待 boost 稳定（软启动）
  3. 设置 `is_running = 1`
  4. 调用 `handle_apply_output()` 按当前手柄的 mA 值输出波形
- **暂停 (0x00)**:
  1. 调用 `handle_stop_output()` 停止 NNC6521 波形输出
  2. 关闭对应手柄的 54V boost
  3. 设置 `is_running = 0`

3. **TODO**: 实际老化测试序列尚未实现

### 6.10 关机请求/确认模块（功能码 0x0A）

**功能描述**: 设备向上位机发送关机请求，等待上位机确认或拒绝。

**设备→上位机（关机请求）**:
| 字段 | 长度 | 说明 |
|------|------|------|
| para[0] | 1B | 0x00（固定，表示关机请求） |

**上位机→设备（确认/拒绝）**:
| 字段 | 长度 | 说明 |
|------|------|------|
| para[0] | 1B | 0x01=确认关机，0x00=拒绝关机 |

**行为**:
1. 设备在 ON 状态下短按电源按钮，发送关机请求（state=ACK, para=0x00）
2. 上位机收到后弹窗让用户选择
3. 选择"是"：上位机发送确认帧（state=ASK, para=0x01），设备执行完整关机序列
4. 选择"否"：上位机发送拒绝帧（state=ASK, para=0x00），设备回到 ON 状态
5. 10s 超时未收到回复：设备自动回到 ON 状态，不关机
6. 开机不需要请求，短按直接开机

### 6.11 温度周期上报模块（功能码 0x0B）

**功能描述**: 设备周期性向上位机上报当前手柄温度。

**帧方向**: 设备→上位机（主动上报，无需上位机请求）

**帧格式**:
| 字段 | 值 | 说明 |
|------|-----|------|
| HEAD | 55 AA | 帧头 |
| LEN | 0x06 | 长度 |
| ADDR | 60 66 | 设备地址 |
| TYPE | 0x01 | 设备应答 |
| STATE | 0x01 | ACK |
| FUNC | 0x0B | 温度上报 |
| handle_id | 1B | 当前活动手柄 ID |
| temp_high | 1B | 温度高字节（temp×10 的 int16 大端序） |
| temp_low | 1B | 温度低字节 |
| CRC16 | 2B | CRC16-MODBUS |

**温度编码**: `temp_encoded = (int16_t)(temperature × 10)`，大端序拆分为 2 字节
- 示例：37.5°C → 375 → 0x0177 → temp_high=0x01, temp_low=0x77
- 范围：-3276.8°C ~ +3276.7°C

**行为**:
1. 治疗开始时启动 2 秒周期定时器
2. 治疗暂停、切换手柄、关机时停止定时器
3. 仅在 is_running=1 时上报
4. NTC 映射：Handle A → NTC_CH_SMALL (PC1)，Handle B → NTC_CH_LARGE (PC0)
5. Handle C 无温度传感器，不上报

### 6.12 PID 参数自整定模块（功能码 0x0C）

**功能描述**: 通过继电反馈法自动整定 PID 参数。

**请求参数**:
| 字段 | 长度 | 说明 |
|------|------|------|
| target_temp | 1B | 目标温度（0~41°C） |

**应答参数（启动时）**:
| 字段 | 长度 | 说明 |
|------|------|------|
| status | 1B | 0x00 = 自整定已启动 |
| kp~kd | 6B | 全部为 0（尚未计算） |

**应答参数（完成时）**:
| 字段 | 长度 | 说明 |
|------|------|------|
| status | 1B | 0x01 = 自整定完成 |
| kp_high | 1B | Kp 高字节（int16×100 大端序） |
| kp_low | 1B | Kp 低字节 |
| ki_high | 1B | Ki 高字节 |
| ki_low | 1B | Ki 低字节 |
| kd_high | 1B | Kd 高字节 |
| kd_low | 1B | Kd 低字节 |

**应答参数（错误时）**:
| 字段 | 长度 | 说明 |
|------|------|------|
| status | 1B | 0x02 = 自整定失败 |
| params | 6B | 全部为 0 |

**算法原理**:
1. 继电反馈法（Relay Feedback）：bang-bang 控制产生等幅振荡
2. 加热器以 100% 加热至 target + 2°C，然后以 0% 降温至 target - 2°C
3. 重复 6 个完整周期
4. 测量振荡周期 Tu 和幅度 Au
5. Ziegler-Nichols 公式：Ku = 4d/(π×a)，Kp=0.6Ku，Ki=2Kp/Tu，Kd=Kp×Tu/8

**安全保护**:
- 过热 45°C 强制中止
- 超时 20 分钟自动中止
- 自整定过程中 PID 安全检查仍然生效

**行为**:
1. 收到命令后启动自整定流程
2. 自整定期间 PID 切换为 bang-bang 控制模式
3. 完成后自动应用新的 PID 参数
4. 通过协议通知上位机结果

### 9.2 电源状态机

```
┌──────────┐  Flag.power_boot_request=1  ┌──────────┐
│  OFF     │ ─────────────────────────→  │ BOOTING  │
│ (待机)   │                             │ (开机中)  │
└──────────┘                             └────┬─────┘

     │ power_do_shutdown()                    ↓

└──────────┘                                 │ Flag.power_shutdown_request=1

                                            └───→ 回到 ON
```

### 9.3 开机流程

触发条件：`KEY_Scan()` 检测到 `KEY_Evt_Press` 事件（系统处于 OFF 状态）→ 设置 `Flag.power_boot_request = 1`

执行序列（`power_boot_sequence()`）：
1. `LED_On(LED_Name_Start)` — PA6 指示灯常亮
2. `BEEP_SetCycleDuty(1000, 1000)` + `BEEP_Blink(1, 0, 0)` — PA7 蜂鸣器响 1s（非阻塞）
3. `bsp_power_enable(1)` — PA4 12V 系统电源使能
4. **不使能 54V 升压**（仅在电刺激输出时开启）
5. 状态切换为 `POWER_STATE_ON`

### 9.4 关机流程

触发条件：`KEY_Scan()` 检测到 `KEY_Evt_Press` 事件（系统处于 ON 状态）→ 设置 `Flag.power_shutdown_request = 1`

执行序列：
1. 发送关机请求帧（func=0x0A, para=0x00）给上位机
2. 状态切换为 `POWER_STATE_WAIT_CONFIRM`
3. 等待上位机回复：
   - 收到确认（para=0x01）→ `Flag.power_shutdown_confirmed = 1` → 执行关机
   - 收到拒绝（para=0x00）→ `Flag.power_shutdown_denied = 1` → 回到 ON 状态
   - 10s 超时无回复 → 自动回到 ON 状态，不关机
4. 确认后执行关机序列（`power_do_shutdown()`）：
   a. `protocol_stop_waveform()` — 停止所有波形输出
   b. `bsp_heater_large_set(0)` + `bsp_heater_small_set(0)` — 关闭加热
   c. `bsp_pump_set(0)` — 关闭气泵
   d. `bsp_boost_1_enable(0)` + `bsp_boost_2_enable(0)` — 关闭 54V 升压
   e. `bsp_power_enable(0)` — 关闭 12V 电源
   f. `BEEP_Blink(1, 0, 0)` + 延时 1s — 蜂鸣器响一声
   g. `LED_Off(LED_Name_Start)` — 关闭指示灯
   h. 状态切换为 `POWER_STATE_OFF`

**注意**：
- 开机不需要上位机确认，短按直接开机
- 关机必须上位机确认，单片机不会自行关机
- 5s 超时强制关机已移除
- 4s 长按强制关机已移除

### 9.5 关机请求/确认协议

| 方向 | 帧内容 | 说明 |
|------|--------|------|
| 设备→上位机 | `55 AA 06 60 66 44 01 0A 00 [crcH] [crcL]` | 关机请求（func=0x0A, state=ACK, para=0x00） |
| 上位机→设备 | `55 AA 06 60 66 44 02 0A 01 [crcH] [crcL]` | 关机确认（func=0x0A, state=ASK, para=0x01） |
| 上位机→设备 | `55 AA 06 60 66 44 02 0A 00 [crcH] [crcL]` | 关机拒绝（func=0x0A, state=ASK, para=0x00） |

### 10.1 NTC 温度传感器规格

| 参数 | 值 |
|------|-----|
| 标称电阻 | 100kΩ @ 25℃ |
| B 值 | 3950K（25/50℃） |
| 电阻精度 | ±1% |
| B 值精度 | ±1% |

### 10.2 ADC 采集方式

使用 RT-Thread ADC 设备框架（`rt_adc_read`），替代 HAL ADC 直接调用。

| 通道 | 引脚 | 用途 |
|------|------|------|
| ADC1_CH10 | PC0 | 小手柄 NTC 温度（TEMP_PID_SMALL） |
| ADC1_CH11 | PC1 | 大手柄 NTC 温度（TEMP_PID_LARGE） |

### 10.3 温度转换方法

采用**查表法 + 线性插值**（`NTC_USE_LOOKUP_TABLE=1`）：
- 176 点查找表，覆盖 -50°C ~ 125°C，步进 1°C
- ADC 值 → 分压公式算电阻 → 二分查找 → 线性插值 → 温度值
- 8 点滑动平均滤波消除 ADC 噪声
- 备选：B 参数公式（Steinhart-Hart 简化版），通过 `NTC_USE_LOOKUP_TABLE=0` 切换

### 10.4 PID 控温算法

**PID 参数**:
| 参数 | 值 | 说明 |
|------|-----|------|
| Kp | 8.0 | 比例增益 |
| Ki | 0.15 | 积分增益（每 100ms） |
| Kd | 3.0 | 微分增益 |
| 控制周期 | 100ms | PID 计算频率 |
| PWM 周期 | 1000ms | 10 个控制周期 |
| 死区 | 0.3°C | 避免继电器抖动 |
| 过热保护 | 45°C | 强制关断 |
| 积分限幅 | -10 ~ +80 | 抗饱和 |

**PID 公式（位置式 + 微分先行）**:
```
error = target - current
P = Kp × error
I += Ki × error  (抗饱和钳位)
D = Kd × (prev_measurement - current)  (微分先行避免设定值突变)
output = P + I + D  (钳位 0~100%)
```

**软件 PWM**:
- output=60% → duty=6/10
- tick 0~5: 加热器 ON
- tick 6~9: 加热器 OFF
- 周期 = 1000ms

### 10.5 温控完整流程

```
上位机发温度指令 [温度=37, 手柄=0x0A]
        ↓
① handle_temp_ctrl()
   - 校验：温度 ≤41，手柄有效，C 手柄拒绝
   - 互斥：关闭另一个手柄的 PID
   - 调用 temp_pid_set_target(A, 37.0)
        ↓
② temp_pid_set_target()
   - 钳位范围 0~41°C
   - 目标变化 >2°C 时重置积分项
   - enabled = 1
   - 目标=0 时直接关加热器
        ↓
③ 10ms 定时器循环调用：
   ┌─ ntc_sensor_update()
   │   - ADC 读取 CH10/CH11
   │   - 8 点滑动平均滤波
   │   - 查表 + 线性插值 → 温度值
   │
   └─ temp_pid_tick()
       └─ 每 100ms（10 次分频）：
           ├─ pid_compute()
           │   - 读当前温度
           │   - 安全检查（过热/传感器故障）
           │   - error = 目标 - 当前
           │   - |error| < 0.3°C → 死区，不调节
           │   - P = Kp × error
           │   - I += Ki × error（抗饱和 ±80）
           │   - D = Kd × (上次温度 - 当前温度)
           │   - 输出 = P + I + D，钳位 0~100
           │   - 超温 >1°C → 输出=0，积分衰减 5%
           │
           └─ pwm_update()
               - output=60% → duty=6/10
               - tick 0~5: 加热器 ON
               - tick 6~9: 加热器 OFF
               - 周期 = 1000ms
```

### 10.6 安全保护机制

| 保护功能 | 阈值 | 动作 |
|----------|------|------|
| 过热保护 | 45°C | 强制关断加热器，禁用 PID |
| 传感器故障 | 连续 10 次异常 | 关断加热器，禁用 PID |
| 积分抗饱和 | I_MAX=80, I_MIN=-10 | 防止积分项过大 |
| 死区 | 0.3°C | 避免在目标附近抖动 |
| 超温保护 | 超过目标 1°C | 输出=0，积分衰减 5% |

### 10.7 加热控制引脚

## 十一、NNC6521 驱动层

### 11.1 芯片初始化流程

```
1. nnc6521_gpio_init()         → 初始化所有 GPIO 引脚
2. nnc6521_init(chip_id)       → 上电序列:
   a. CHIP_EN = LOW（复位）
   b. 延时 ~10ms
   c. CHIP_EN = HIGH（使能）
   d. 延时 ~10ms
   e. 写 PMU 寄存器: 复位波形发生器
   f. 配置时钟: PCLK 分频 = 1（2MHz）
   g. 全局驱动使能
```

### 11.2 波形发生器配置流程

```
1. 禁用目标通道 AWG
2. 使能模拟通道 (ANA_ENABLE_REG)
3. 写入配置寄存器组:
   - 采样点数 (POINT_CONFIG)
   - 配置寄存器 (CONFIG_REG0): rest/negative/silent/sourceB/multi_electrode/continue
   - 静默时间 (SILENT_CLK): 24-bit
   - 正半波间隔 (HALF_WAVE_CLK_PNT): 16-bit
   - 负半波间隔 (NEG_HALF_WAVE_CLK_PNT): 16-bit
   - 驱动电流寄存器 2 (DRIVE_REG_CTRL2)
   - 死区时间 (REST_CLK): 16-bit
   - 中断配置 (INT_NUM_WAVE, INT_REG01~03)
4. 若为 SPI 波形:
   a. 通过 OTP 校准数据计算电流
   b. 生成缩放波形数组 (16-bit → 8-bit)
   c. 逐点写入波形数据到 Waveform RAM
5. 配置交替模式寄存器
6. 使能 AWG
```

### 11.3 电流校准系统

- 校准数据存储在 NNC6521 OTP 内存中
- 25 个校准点（范围 3~25）
- CH1 校准基地址: `0x00`
- CH2 校准基地址: `0x32`
- 校准流程: 读取 OTP Dref → 计算 Ival = (Ireq × 1000) / Dref → 限制最大 4096

### 11.4 安全检测

#### 11.4.1 导联脱落检测 (LOD - Lead-Off Detection)

- 检测模式: 高电平检测
- 检测通道: CH1 + CH2 同时（LO_ALL）
- 寄存器组: `0x30~0x3B`（LEAD_OFF_xxx）
- 中断使能位: `LEAD_OFF_INT.lead_off_int_en`
- 配置参数: 阈值（16-bit）、延迟、目标值

#### 11.4.2 短路检测 (SCD - Short-Circuit Detection)

- 双通道独立检测
- 通过 DAC 阈值比较器实现
- 寄存器组: `ANA_INT_SIMx_xxx`, `ANA_INT_CHx_INT_NUMBER`
- 中断清零: 写 `ANA_INTR_SIM_CL = 0x03`

```
        ↓

   - 如果正在运行：直接调用 handle_apply_output() 更新波形
   - 返回 ACK
        ↓
上位机开始治疗指令 [0x05, 0x01]
        ↓
④ handle_start_pause(1)
   - 使能 54V boost（手柄 B → boost_1 PB0）
   - 延时 10ms 等待 boost 稳定
   - is_running = 1
   - handle_apply_output(handle_idx=1)
     → waveform_apply(CHIP_1, CH1, 3, 50mA)
       → nnc6521_wavegen_config()：禁用 AWG → 配置寄存器 → 使能 AWG
   - 启动温度上报定时器（2s 周期）
   - 返回 ACK
        ↓
治疗运行中...
   - NNC6521 持续输出波形
   - 10ms 定时器：NTC 温度采集 + PID 控温
   - 2s 定时器：温度上报
        ↓
上位机暂停治疗指令 [0x05, 0x00]
        ↓
⑤ handle_start_pause(0)
   - 禁用 AWG
   - 关闭 54V boost
   - is_running = 0
   - 停止温度上报定时器
   - 返回 ACK
```

### 启动初始化（main.c）

```c

ntc_sensor_init();       // NTC 传感器模块初始化
                         //   → rt_device_find("adc1")
                         //   → rt_adc_enable(ch10)
                         //   → rt_adc_enable(ch11)
                         //   → 清零滤波缓冲区
temp_pid_init();         // PID 控温模块初始化
                         //   → Kp=8.0, Ki=0.15, Kd=3.0
                         //   → 清零所有 PID 状态
                         //   → 关闭所有加热器
```

### 温控完整流程

```
上位机发温度指令 [0x03, 0x25, 0x0A]（设置 37°C，手柄 A）
        ↓
① handle_temp_ctrl()
   - 校验：温度 ≤41，手柄有效，C 手柄拒绝
   - 互斥：关闭手柄 B 的 PID（temp_pid_set_target(B, 0)）
   - 调用 temp_pid_set_target(SMALL, 37.0)
        ↓
② temp_pid_set_target()
   - 钳位 0~41°C
   - 目标变化 >2°C → 重置积分项
   - enabled = 1
   - 目标=0 → 直接关加热器
        ↓
③ 10ms 定时器循环（sysTimer 回调）
   ┌─ ntc_sensor_update()
   │   - rt_adc_read(adc_dev, CH10) → 大手柄 NTC 原始值
   │   - rt_adc_read(adc_dev, CH11) → 小手柄 NTC 原始值
   │   - 8 点滑动平均滤波
   │   - 查表 + 线性插值 → 温度值
   │
   └─ temp_pid_tick()
       └─ 每 100ms（10 次分频）：
           ├─ pid_compute()
           │   - 读当前温度
           │   - 安全检查（过热 45°C/传感器故障）
           │   - error = 37.0 - 当前温度
           │   - |error| < 0.3°C → 死区，不调节
           │   - P = 8.0 × error
           │   - I += 0.15 × error（抗饱和 -10~+80）
           │   - D = 3.0 × (上次温度 - 当前温度)
           │   - 输出 = P + I + D（钳位 0~100）
           │   - 超温 >1°C → 输出=0，积分衰减 5%
           │
           └─ pwm_update()
               - output=60% → duty=6/10
               - tick 0~5: 加热器 ON (PC10)
               - tick 6~9: 加热器 OFF
               - 周期 = 1000ms
```

### 温度上报流程

```
治疗开始 → handle_start_pause(1)
        ↓
protocol_temp_report_start(handle_id)
   → 创建 2s 周期定时器
   → 启动定时器
        ↓
每 2 秒触发回调 temp_report_timer_cb()
   → 读取当前手柄温度
   → 编码：temp × 10 → int16 → 大端序拆分
   → 构建帧：55 AA 06 60 66 44 01 0B [handle] [tempH] [tempL] [CRC]
   → 通过 UART1 发送
        ↓
治疗暂停/切手柄/关机 → protocol_temp_report_stop()
   → 停止定时器
```

### PID 自整定流程

```
上位机发自整定指令 [0x0C, 0x25]（目标 37°C）
        ↓
① handle_pid_autotune()
   → temp_pid_autotune_start(pid_idx, 37.0)
   → 关闭正常 PID 控制
   → 初始化自整定状态
   → 立即开启加热器（100%）
   → 返回启动 ACK [0x00, 0,0,0,0,0,0]
        ↓
② temp_pid_tick() 中处理自整定逻辑
   ┌─ 温度上升至 37 + 2 = 39°C
   │   → 关闭加热器（0%）
   │   → 记录高温峰值
   │
   └─ 温度下降至 37 - 2 = 35°C
       → 开启加热器（100%）
       → 记录低温谷值
       → 记录周期时间
       → cycle_count++
        ↓
③ 达到 6 个周期
   → 计算平均周期 Tu = period_sum / 6
   → 计算振荡幅度 a = (temp_high - temp_low) / 2
   → Ku = 4 × 50 / (π × a)
   → Kp = 0.6 × Ku
   → Ki = 2 × Kp / Tu（per-second → per-100ms 转换）
   → Kd = Kp × Tu / 8
   → 应用新参数
   → 恢复正常 PID 模式
   → 返回完成 ACK [0x01, kpH, kpL, kiH, kiL, kdH, kdL]
        ↓
异常处理
   - 超温 45°C → 强制中止，返回 [0x02, ...]
   - 超时 20 分钟 → 自动中止，返回 [0x02, ...]
```

### 手柄-温控映射

| 手柄 | PID 实例 | NTC 通道 | 加热器引脚 | Boost |
|------|----------|----------|-----------|-------|
| A (0x0A) | TEMP_PID_SMALL | CH11 (PC1) | PC10 | PB0 |
| B (0x0B) | TEMP_PID_LARGE | CH10 (PC0) | PC11 | PB0 |
| C (0x0C) | 无 | 无 | 无 | PB1 |

**温控互斥**：同一时间只有一个手柄的 PID 可以运行。
