## 关键说明

- **加热 GPIO**: 小手柄 → PC10，大手柄 → PC11（非 PC12）
- **54V 升压**: 开机时不使能，仅在电刺激输出时开启
- **关机流程**: 单片机短按电源按钮发送关机请求(func=0x0A, para[0]=0x00)给上位机，上位机确认(para[0]=0x01)后执行关机；10s 超时未回复则不关机，自动回到 ON 状态
- **气泵控制**: PB10 简单开/关控制（高电平=使能，低电平=关闭），无 PWM 调速
- **测试编号格式**: `P{阶段}-{序号}`（如 `P1-01`、`P2-01`）

## 阶段一：电源与开机流程

电源管理和开关机流程测试。

### 1.1 开机流程

- [ ] **P1-01** 按钮检测：PA5 低电平持续 ≥1s → 系统检测到稳定按下
- [ ] **P1-02** 指示灯亮起：开机后 → PA6 输出高电平 → LED 常亮
- [ ] **P1-03** 蜂鸣器鸣叫：开机后 → PA7 输出高电平 1s → 蜂鸣器响 1s 后停止
- [ ] **P1-04** 12V 电源使能：开机后 → PA4 输出高电平 → 12V 电源接通
- [ ] **P1-05** 54V 升压不开机：开机后 → PB0=低, PB1=低 → 54V 升压未使能
- [ ] **P1-06** 开机时序验证：按钮 → LED → 蜂鸣器 1s → 12V 使能 → 通过 Debug 日志验证时序

### 1.2 关机流程

- [ ] **P1-07** 关机请求发送：短按 PA5（在系统 ON 状态下）→ 单片机通过 UART1 发送 func=0x0A 关机请求（para[0]=0x00）
- [ ] **P1-08** 上位机确认接收：上位机回复 func=0x0A, para[0]=0x01 → 单片机执行完整关机序列
- [ ] **P1-09** 关机输出切断：收到 ACK → 关闭 54V 升压(PB0/PB1=低)、关闭气泵(PB10=低)
- [ ] **P1-10** 关机 12V 切断：输出关闭后 → PA4=低 → 12V 电源断开
- [ ] **P1-11** 关机蜂鸣器：断电后 → PA7 高电平 1s → 蜂鸣器响一声
- [ ] **P1-12** 关闭指示灯：蜂鸣器结束后 → PA6=低 → LED 熄灭
- [ ] **P1-13** 关机超时处理：上位机 10s 内未回复 → 单片机不关机，自动回到 ON 状态
- [ ] **P1-14** 治疗中关机：运行状态 → 短按 → 发送关机请求 → 上位机确认 → 验证输出先停止再断电

### 1.3 GPIO 独立验证

- [ ] **P1-15** PA4 (12V 使能)：置高 → 12V 通；置低 → 12V 断
- [ ] **P1-16** PA5 (按钮)：默认高电平；按下 → 低电平；松开 → 高电平
- [ ] **P1-17** PA6 (LED)：置高 → 亮；置低 → 灭
- [ ] **P1-18** PA7 (蜂鸣器)：置高 → 响；置低 → 停
- [ ] **P1-19** PB0 (54V 升压 1)：置高 → LGS6302EP-1 使能；低 → 关闭
- [ ] **P1-20** PB1 (54V 升压 2)：置高 → LGS6302EP-2 使能；低 → 关闭
