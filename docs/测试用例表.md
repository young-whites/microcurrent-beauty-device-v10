# DJM-V10 微电流美容仪 — 模块化功能测试用例表

> **版本**: V1.0  
> **日期**: 2026-07-08  
> **适用平台**: STM32F103RCT6 / RT-Thread v5.1.0  
> **测试工具**: UART1 (9600bps) 上位机 + UART2 (115200bps) Debug 日志 + 万用表 + 示波器

---

## 一、测试环境

| 项目 | 说明 |
|------|------|
| 上位机 | Android APP 或 PC 串口工具（发送协议帧） |
| Debug 口 | UART2 (115200bps) 观察日志输出 |
| 测量工具 | 万用表（电压/电流/电阻）、示波器（波形/频率/脉宽）、温度计 |
| 供电 | 12V 系统电源（PA4 高电平使能） |
| NTC 模拟 | 精密电阻箱（模拟 NTC 阻值）或实际 NTC 探头 + 加热源 |

## 二、协议基础模块

### 2.1 帧解析与校验

| 编号 | 测试项 | 输入/操作 | 预期结果 | 通过 |
|------|--------|-----------|----------|------|
| P-01 | 正常帧解析 | 发送标准帧 `55 AA 05 60 66 44 02 08 7D DE` | 设备正确解析并返回版本号 ACK | ☐ |
| P-02 | CRC 错误检测 | 修改 CRC 字节后发送 | 设备丢弃该帧，不返回 ACK | ☐ |
| P-03 | 帧头错误 | 发送错误帧头 `56 AA ...` | 设备丢弃，状态机回到 IDLE | ☐ |
| P-04 | 地址错误 | 修改设备地址字节后发送 | 设备丢弃，不响应 | ☐ |
| P-05 | 超长帧处理 | 发送超过 64 字节的帧 | 设备丢弃，不崩溃 | ☐ |
| P-06 | 超短帧处理 | 发送不完整帧（仅帧头） | 设备丢弃，状态机超时复位 | ☐ |
| P-07 | 连续帧发送 | 快速连续发送 10 帧不同指令 | 全部正确解析和应答，无丢帧 | ☐ |
| P-08 | 环形缓冲区满载 | 大量数据灌入 UART RX | 缓冲区满时丢弃新数据，不溢出 | ☐ |
